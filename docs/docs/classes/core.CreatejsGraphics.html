    Class CreatejsGraphics

    inherited createjs.Graphics

    createjs.Graphics is a command object, not a display object (no EventDispatcher, no initialize) - a Shape holds it rather than it being added to a container directly, so this wrapper does not implement ICreatejsDisplayObject.
